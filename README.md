EXPLANITION BUT NOT FOR A 12 Y OLD: is a set of instructions designed to solve a particular problems,
 perform calculations, or manipulate data efficiently.
  EX : TO PREPARE A DISH you need:
    Ingredients(noodeles, taste maker; water)------->Recipe(boil water, pour water into cup, add taste maker, close lid, and wait 4 minutes)--------->Tasty-dish(result)
  IN PROGRAMMIG : 
  Ingredients as (inputs)----->Recipe as(Algorithms)------>tasty-dish as(Output)

  EX : Inputs(Two Numbers a and b)------>Algorithms(Add Numbers using + then retrun the value)------>Output(Sum of a and b)
  NOTE : the problem to solve here is adding the number a to number b

  Characteristics : 
  1.Input and Output Specified : Input precision requires that you know what kind of data, how much and what form the data should be
  the same as output

  2.Definiteness : Definiteness means specifying the sequence of operations for turning input into output.

  3.Effectiveness :  all those steps that are required to get to output must be feasible with the available resources.

  4.Finteness : .An algorithm should not be infinite and always terminate after definite number of steps.

  5.Independent : An algorithm should have step-by-step directions.

  Big_O Notation for worst cases : 
  O(1) — constant time
  O(log n) — logarithmic
  O(n) — linear
  O(n log n) — common in efficient sorting
  O(n²) — nested loops and pair comparisons
  Space complexity — how much additional memory an algorithm uses
